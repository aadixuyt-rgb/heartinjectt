# AdixFX Backtrack + Wall Hitboxes

Minecraft 1.21.4 Fabric client mod snapshot based on AdixuFX. This repository contains the separate experimental variant with client-side Backtrack and player hitbox outlines rendered through walls.

- Target: Minecraft 1.21.4
- Loader: Fabric
- Java: 21
- Backtrack: optional toggle in the Hitbox settings
- Player hitbox outlines: rendered through blocks (visual only)

Note: bundled audio files are not included in this repository snapshot. This source import has not yet been built or tested in-game.
