# Back Track

Minecraft 1.21.4 Fabric client mod. Includes the client GUI and settings, Backtrack, player hitbox outlines, music player, HUD tools, and visual effects.

- Target: Minecraft 1.21.4
- Loader: Fabric
- Java: 21
- Mod name: Back Track
- Backtrack: optional toggle in the Hitbox settings
- Player hitbox outlines: visual player outlines through blocks

Note: bundled audio files are not included in this repository snapshot. The source has a successful CI build; in-game behavior has not yet been verified.
